## 🌟 Key Highlights & Architecture

- ⚡ **Modern Stack**: Built with React 19, TypeScript, Vite 6, and Tailwind CSS v4.
- 🎨 **Rich Glassmorphic Aesthetics**: Cosmic dark theme (`#05050a`) & crisp light theme with real-time toggle.
- 🤖 **Interactive Showcase**: Multi-field search, category filtering, deep-dive project modals, and sequential screenshot lightboxes.
- 📜 **Verified Credentials Ledger**: 1-click preview and download for authentic, original certification PDFs.
- 📨 **Live Contact Pipeline**: Real-time email delivery to `ijlalhussain.eng@gmail.com` via Web3Forms API.
- 📱 **Progressive Web App (PWA)**: Installable standalone app on Android & iOS with manifest and icon cache.
- 🌐 **Rich Social Media Previews**: 1200×630 OpenGraph and Twitter card integration.

```bash

# 2. Install dependencies
npm install

# 3. Start local development server
npm run dev
```
